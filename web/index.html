DeadDrop

Sell encrypted files on NEAR. Buyers pay into escrow and get a decryption key sealed to their own public key; the seller is paid only when the key is delivered, and the buyer gets a refund if it never is. A dead-man switch releases a file to an heir if its owner stops checking in.

1 · DropSeller encrypts a file (AES-256-GCM) and lists its hash, price and keeper with create_drop.
2 · BuyBuyer calls buy with an x25519 public key. Payment sits in escrow.
3 · DeliverThe keeper seals the content key to that public key and calls deliver_key; escrow pays the seller.
4 · Fail-safesNo key in time → claim_refund. Owner silent → anyone can trigger_release to the heir.
